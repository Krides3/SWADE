▸ OPERATOR DATA BACKUP

Export all operator accounts to a file. Import to restore after clearing browser data or switching devices. The file contains hashed credentials — keep it secure.

▸ LOCK IN ROSTER (PERMANENT SAVE)

Bakes the current roster into auth.js as permanent defaults. Download the file, replace the existing auth.js, then push to git. After that, accounts auto-restore even if browser data is cleared.

▸ MINIGAME CONTROL

Each minigame has an embedded Overlord panel. Open the terminal to configure sequences, difficulty, and game state. Changes persist for all connected operators.

▸ ASSET MAP SETTINGS

Controls how fast vehicles move on the Asset Map. 1× = real-time (Paris→NY ≈ 7 hours). 5× ≈ 80 min/transatlantic. 300× ≈ 80 sec (old default). Changes take effect immediately on the live map — no reload needed.
